# Releasing Memora

Memora ships through two complementary channels, for two different audiences:

- **Homebrew + GitHub Releases** distribute the `memora` CLI binary to end users
  (`brew install`, a `curl | sh` installer, and downloadable archives). This is the
  path most people use to run `memora demo`.
- **crates.io** publishes the libraries so Rust developers can embed the engine
  (`cargo add memora-core`) and the `Memora` facade. This is the SDK path.

They are not either/or. The CLI goes to Homebrew; the library goes to crates.io.

## 1. Bump the version

Versions live in two places that must stay in step:

- `workspace.package.version` in the root `Cargo.toml` (all crates inherit this).
- The three internal entries in `[workspace.dependencies]` of the root `Cargo.toml`
  (`memora-core`, `memora-llm`, `memora-mcp`), whose `version` is what crates.io uses.

Update both, then update `CHANGELOG.md` (move `Unreleased` to the new version), and
commit.

## 2. Tag, which triggers binaries + Homebrew (cargo-dist)

```bash
git tag v0.1.29
git push origin v0.1.29
```

The `Release` workflow (generated by [dist](https://opensource.axo.dev/cargo-dist/))
builds binaries for macOS, Linux, and Windows, attaches a shell installer, and
publishes the Homebrew formula to the tap.

### One-time Homebrew setup (required before the first brew release)

1. Create an empty public repo named **`radotsvetkov/homebrew-tap`**.
2. Create a fine-grained Personal Access Token with `contents: write` on that tap
   repo, and add it to the **memora** repo as the secret **`HOMEBREW_TAP_TOKEN`**.

After the next release, users can install with:

```bash
brew install radotsvetkov/tap/memora
```

Until the tap and token exist, the `publish-homebrew-formula` job will fail (the rest
of the release still succeeds). Do the setup above first.

## 3. Publish the libraries to crates.io

Publish in dependency order, because each crate must resolve the previous one from
the registry:

```bash
cargo publish -p memora-llm
cargo publish -p memora-core
cargo publish -p memora-mcp   # optional: only if exposing the MCP server as a lib
cargo publish -p memora-cli   # optional: enables `cargo install memora-cli`
```

`memora-llm` and `memora-core` are the SDK. `memora-cli` is also distributed as a
binary via Homebrew, so publishing it to crates.io is optional (it just enables
`cargo install memora-cli` for Rust users).

Verify readiness without uploading:

```bash
cargo publish -p memora-llm --dry-run
# memora-core dry-run only fully works once memora-llm is on crates.io
```
